# 🎯 Guess The Number Game

A simple and interactive number guessing game built using HTML, CSS, and JavaScript.

## 📌 Features
- Random number generated between 1 to 100
- User input to guess the number
- Instant feedback (Too High / Too Low / Correct)
- Dynamic UI color changes
- Beginner-friendly logic

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript (DOM Manipulation)

## 📂 Project Structure
├── index.html  
├── style.css  
├── script.js  

## 🧠 How It Works
1. A random number is generated using JavaScript
2. User enters a number
3. The system checks:
   - If higher → "Too High"
   - If lower → "Too Low"
   - If equal → "Correct"
4. Result is displayed with color feedback
